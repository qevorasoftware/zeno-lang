What this honestly does

        

          Speech-in and speech-out are the browser's engines: whether your language is
          recognised or pronounced depends on the browser and the operating system, not on this
          page. The turn itself always carries the language tag unchanged, and it is stored with
          the record.
        

        

          A voiceprint (when audio is attached) is measured by the server and kept as a
          signal: recorded speech replays, so it never authorizes anything by itself.
          Memory is sealed with the AEGIS hybrid sealer when ZENO_MEMORY_KEY is set —
          the Posture panel says which mode you are in. The guardian watches the rate of
          requests: a burst far above your own baseline is refused as anomalous, which is the
          layer working, not a bug. Talk at a human pace, or raise the ceiling deliberately with
          ZENO_SENTINEL_MAX_EVENTS_PER_MINUTE=… when a fast client is expected. Connected-agent replies are stored with
          the peer's name attached, because a peer's answer is that peer's claim, not a fact.
